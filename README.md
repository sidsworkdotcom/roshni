# Next.js 16 Template

A modern, opinionated **Next.js 16 starter template** built for performance, maintainability, and clean developer experience.  
Pre-configured with **React 19, Tailwind CSS v4, ESLint, Prettier, sitemap generation, and smooth UX utilities** — so you can focus on shipping instead of setup.

---

## ✨ Features

- **Next.js 16.1.6** — App Router, Server Components, and optimized builds
- **React 19** — Latest concurrent features and compiler support
- **Tailwind CSS v4** — Utility-first styling with class merging & animations
- **SEO Ready** — Automatic sitemap generation with `next-sitemap`
- **Code Quality**
  - ESLint (Next.js config)
  - Prettier with Tailwind, import, and attribute organizers
- **UX Enhancements**
  - `nextjs-toploader` — Route change progress bar
  - `lenis` — Smooth scrolling
  - `lucide-react` — Clean, modern icons
- **TypeScript First** — Strict typing out of the box
- **Production Friendly** — Clean builds, formatting checks, and post-build hooks

---

## 📦 Tech Stack

- **Framework:** Next.js 16
- **UI:** React 19, Tailwind CSS 4, tw-animate-css
- **Icons:** Lucide React
- **SEO:** next-sitemap
- **Utilities:** clsx, class-variance-authority, tailwind-merge, lenis
- **Tooling:** TypeScript, ESLint, Prettier
